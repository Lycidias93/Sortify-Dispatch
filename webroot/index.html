Safety contract

Runtime boundaries reported by the adapter and enforced by the server.

  • The server binds only to 127.0.0.1.
  • A one-time bootstrap token becomes an HttpOnly browser session.
  • Mutations require exact same-origin requests and a custom request guard.
  • JavaScript cannot submit arbitrary shell commands or filesystem paths.
  • Module Action can open the default browser; supported embedded root-manager hosts only bootstrap the same loopback session and then leave the manager bridge path.
  • The WebUI is not a boot dependency.
