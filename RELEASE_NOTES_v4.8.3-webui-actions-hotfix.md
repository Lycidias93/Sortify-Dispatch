# Sortify Dispatch 4.8.3 – WebUI Actions Hotfix

- Keeps long action output in a bounded Actions result panel so the mobile WebUI remains usable.
- Labels safe read-only actions as **Run check** instead of **Apply change**.
- Preserves detailed adapter error output for failed actions instead of collapsing it into a generic backend failure.
- Reports the installed Sortify version in action and guard output instead of a stale 4.7.1 label.
- Keeps focused WebUI form controls visible above the Android software keyboard.

Existing Sortify settings and persistent configuration are preserved.
